# Arsip Contoh Soal (Tahun Ajaran 2024/2025)

Direktori ini disiapkan untuk menampung berkas PDF soal Tahun Ajaran 2024/2025.

> **Catatan:**  
> Program resmi **Tes Kompetensi Akademik (TKA) Kemendikdasmen** baru pertama kali diluncurkan secara nasional pada **Tahun Ajaran 2025/2026** (Kementerian Pendidikan Dasar dan Menengah baru dibentuk pada akhir 2024).  
> Jika Anda memiliki berkas soal arsip mandiri (seperti Ujian Sekolah, latihan asesmen, atau UTBK 2024), Anda bisa meletakkannya di folder ini (`Contoh_Soal_<Mapel>.pdf`), dan sistem otomatis akan langsung memunculkannya di katalog web.
