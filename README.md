# Bank Soal TKA Kemendikdasmen

Portal unduh dan pratinjau interaktif kumpulan soal resmi Tes Keterampilan Akademik (TKA) Kemendikdasmen untuk 22 mata pelajaran SMA/SMK dalam format PDF.

---

## 📚 Ringkasan Konten

- **Tahun Ajaran:** 2025/2026 *(Arsip aktif, siap diperbarui secara berkala setiap tahun ajaran baru)*
- **Total Mata Pelajaran:** 22 Mapel
- **Total Butir Soal:** 643 Soal
- **Format Berkas:** PDF bersih tanpa header browser `file:///` atau tanggal.
- **Kategori:**
  - 🔵 **Wajib / Umum (4 Mapel):** Matematika, Bahasa Indonesia, Bahasa Inggris, PPKn
  - 🟢 **MIPA (4 Mapel):** Fisika, Kimia, Biologi, Matematika Tingkat Lanjut
  - 🟡 **IPS / Soshum (5 Mapel):** Ekonomi, Geografi, Sosiologi, Sejarah, Antropologi
  - 🟣 **Bahasa & Budaya (2 Mapel):** Bahasa Indonesia Lanjut, Bahasa Inggris Lanjut
  - 🔴 **Bahasa Asing (6 Mapel):** Bahasa Arab, Bahasa Jepang, Bahasa Mandarin, Bahasa Jerman, Bahasa Korea, Bahasa Prancis
  - 🔷 **Kejuruan / Vokasi (1 Mapel):** Projek Kreatif & Kewirausahaan (PKK)

---

## 🚀 Fitur Portal

1. **Pencarian Real-Time & Filter Kategori:** Temukan mata pelajaran secara instan.
2. **Pratinjau Langsung (In-App PDF Preview):** Membaca soal langsung di modal tanpa harus mengunduh terlebih dahulu.
3. **Direct Download:** Tombol unduh langsung untuk setiap mata pelajaran.
4. **Optimasi Vercel:** Dilengkapi konfigurasi `vercel.json` dengan caching header untuk loading dan unduhan PDF yang cepat.

## 🛠️ Deploy Sendiri ke Vercel

1. Buka [Vercel Dashboard](https://vercel.com/new).
2. Pilih repository `bank-soal-tka`.
3. Klik **Deploy** (otomatis terdeteksi sebagai situs statis).
